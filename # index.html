Sobre o Projeto

Este repositório é destinado à documentação do projeto do curso de Mecatrônica, desenvolvido no laboratório (Sala 104). O trabalho abrange o desenvolvimento de estruturas mecânicas, circuitos eletrônicos e programação de sistemas de controle.
